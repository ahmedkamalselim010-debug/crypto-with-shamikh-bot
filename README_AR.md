# بوت Crypto with Shamikh — دليل الإعداد

## ماذا يفعل؟
- كل 6 ساعات يحاول نشر تحديث فني لـ Bitcoin وEthereum.
- يحسب EMA20 وEMA50 وRSI(14) على شموع ساعة واحدة من بيانات Binance العامة.
- يجلب أخبار CoinDesk عبر RSS، ويمنع إعادة نشر العناوين القديمة باستخدام state.json.
- لا ينفذ صفقات ولا يحتاج إلى مفاتيح تداول أو بيانات دخول لمنصة تداول.

## تنبيه مهم
هذه نسخة أولية تجريبية. المؤشرات بسيطة وليست استراتيجية مثبتة الربحية، ولا توفر مستويات دخول أو وقف خسارة أو أهداف. لا توجد أرباح مضمونة. تحقق من الأخبار والبيانات ولا تعتمد عليها وحدها في قرارات مالية.

## الإعداد خطوة بخطوة

1. افتح https://t.me/BotFather وأرسل `/newbot`. اتبع التعليمات واحفظ Bot Token بسرية.
2. افتح قناة Crypto with Shamikh > إدارة القناة > Administrators > Add Admin. أضف البوت وامنحه صلاحية نشر الرسائل.
3. أنشئ مستودع GitHub جديدًا باسم `crypto-with-shamikh-bot`.
4. ارفع `bot.py` و`state.json` و`README_AR.md` ومجلد `.github/workflows` بما فيه `publish.yml`.
5. من Settings > Secrets and variables > Actions > New repository secret أضف:
   - `TELEGRAM_BOT_TOKEN` = التوكن من BotFather
   - `TELEGRAM_CHANNEL_ID` = `@CryptoWithShamikh` إذا كان هذا هو اسم المستخدم العام الحالي لقناتك.
6. افتح تبويب Actions وفعّل الـ workflow إذا طلب GitHub ذلك.
7. اختر `Crypto with Shamikh scheduled posts` ثم `Run workflow` للاختبار الأول.
8. راجع سجل التشغيل وتأكد من وصول رسالة تحديث السوق. أول تشغيل يهيّئ قائمة الأخبار فقط لتجنب نشر عناوين قديمة؛ تبدأ متابعة الأخبار الجديدة بعد ذلك.
9. بعد نجاح الاختبار، سيحاول GitHub Actions التشغيل كل 6 ساعات. الجدولة قد تتأخر، والخدمة المجانية تخضع لحدود GitHub الحالية.

## أمان
- لا تضع التوكن داخل `bot.py` أو في ملفات عامة أو في محادثة.
- إذا انكشف التوكن، ألغِه وأصدر غيره عبر BotFather.
- لا تضف مفاتيح API للتداول؛ البوت لا يحتاج إليها.
- إذا فشل RSS أو مصدر الأسعار، راجع سجل Actions. لا تشارك سجلات تحتوي على أسرار.
